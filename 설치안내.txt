로스트아크 보석 시세: 무료 자동 분석 패치
====================================

설치 위치: 기존 GitHub 저장소 personal-gem-tracker

변경/추가되는 파일
- discord_notify.py                   기존 파일 덮어쓰기
- .github/workflows/collect.yml      기존 파일 덮어쓰기
- tests/test_discord_notify.py       새 파일 추가

그대로 유지되는 파일
- collect.py
- data/gems.csv (기존 누적 시세 절대 삭제하지 말 것)
- data/latest.md (기존 보고서)
- GitHub Secrets: LOSTARK_API_KEY, DISCORD_WEBHOOK_URL (수정 불필요)

수집 시각: 매일 오전 09:17, 오후 21:17 한국시간 (GitHub 예약 지연 가능)
수집 종료: 2026-11-15 (기존 조건 유지)

추가 기능: 디스코드에 자동 표시
1. 이전 수집 대비 즉시구매 최저 호가 증감률(%).
2. 최근 3일/7일 평균 가격 (한국 날짜별 1일 평균 → 다시 기간 평균).
   날짜별 기록이 한 번이라도 빠지면 '자료 부족'으로 표시함.
3. 이전 수집 대비 경매장 등록 매물 건수 증감.
4. 10레벨 완제품 / 9레벨 3개 / 8레벨 9개 가격 비교.
   겁화/작열 중 최저 호가로 각각 계산하므로 합성 결과 종류는 보장 안 됨.
5. 이전 수집 대비 가격이 5% 이상 하락한 보석에 '🚨 급락 감지' 표시.
   기준을 바꾸려면 collect.yml에서 PRICE_DROP_ALERT_PCT: '5'의 숫자 수정.

설치 방법
1. GitHub Desktop에서 personal-gem-tracker 선택 → Fetch origin → 필요 시 Pull origin.
2. Show in Explorer로 연 저장소 폴더에 이 ZIP의 위 3개 파일을 경로 그대로 복사.
3. GitHub Desktop Changes에서 변경 3개 확인.
4. Summary: Add free gem analytics → Commit to main → Push origin.
5. GitHub Actions → Lost Ark Gem Snapshot → Run workflow로 수동 실행 테스트.
6. 디스코드 '보석-시세' 채널에서 6종 보석 가격·평균·매물·합성비를 확인.

주의사항
- 추가 API 키가 필요하지 않음. OpenAI API 호출 및 과금 없음.
- 등록 매물 건수는 거래량/체결량이 아님.
- 3일/7일 평균은 수집이 누적되고 해당 날짜들이 채워져야 출력됨.
- 급락 알림은 임계값을 충족한 스냅샷의 디스코드 보고서에서만 표시됨.
- 알림 수신은 Discord 휴대폰의 해당 채널 알림 설정에 따라 달라짐.
- 기존 data/gems.csv를 덮어쓰거나 삭제하지 마.
