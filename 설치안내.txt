로스트아크 보석 추적기: 3시간마다 간단 가격 알림 + 하루 2회 전체 보고서
=================================================================
대상 저장소: https://github.com/belzer0710-lgtm/personal-gem-tracker

한국시간 예약:
- 00:17 / 03:17 / 06:17 / 12:17 / 15:17 / 18:17
  -> 보석 6종 가격, 직전 대비 변동률, 등록 매물과 증감량을 담은 간단 디스코드 가격 알림 (1회)
- 09:17 / 21:17
  -> 위 가격·매물 정보를 포함해 3일/7일 평균, 24시간 변화, 합성 비용까지 담은 전체 보고서 (1회)
- 수동 Run workflow
  -> 전체 보고서 (테스트용)

=> 총 8회 수집, 총 8개의 정기 디스코드 메시지 (간단 6회 + 전체 2회).
=> 약 24시간 전보다 가격이 -5% 이하로 처음 떨어지면 간단 알림에도 급락 경고 강조.
=> GitHub Actions 예약 실행은 지연되거나 누락될 수 있음.

교체/추가할 파일 3개:
1. discord_notify.py                 -> 기존 파일 덮어쓰기
2. .github/workflows/collect.yml    -> 기존 파일 덮어쓰기
3. tests/test_discord_notify.py     -> 기존 파일 덮어쓰기/없으면 추가

절대 덮어쓰거나 삭제하지 않을 파일:
- collect.py (기존 공식 API 수집기)
- data/gems.csv (누적 시세 원본)
- data/latest.md (최신 보석 보고서)
- GitHub Secrets LOSTARK_API_KEY / DISCORD_WEBHOOK_URL

GitHub Desktop 설치 단계:
1. 저장소 personal-gem-tracker 선택.
2. Fetch origin -> Pull origin(필요할 경우)으로 최신 내용 내려받기.
3. Show in Explorer로 저장소 폴더 열기.
4. ZIP 내 파일 3개를 해당 경로에 붙여넣기, 기존 파일 덮어쓰기.
5. Changes에서 수정파일을 확인하고 Summary: Price updates every 3h + reports twice daily
6. Commit to main -> Push origin.
7. GitHub Actions > Lost Ark Gem Snapshot > Run workflow. 초록 체크와 디스코드 전체 보고 확인.
8. 다음 예약 실행에서는 간단 알림 또는 전체 보고가 도착하는지 확인.

휴대폰으로 직접 수정할 경우:
- GitHub 웹사이트에서 .github/workflows/collect.yml 의
  DISCORD_REPORT_MODE 조건식에서 끝의 'alert_only' 를 'price' 로 바꿈.
- 단, 전체 변경 기능(간단 가격 메시지 포함)을 쓰려면 discord_notify.py도 이 ZIP 버전으로 교체해야 함.
